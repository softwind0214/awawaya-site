隐私政策（Privacy Policy）

应用名称：Awawaya · 生效日期：2026-10-17 · 适用范围：Awawaya 应用及其关联页面

1. 概述

Awawaya（下称"本应用"）为应用所有者（下称"所有者"）的个人自用工具，不面向公众提供服务。本政策详细说明本应用如何访问、使用、存储和保护通过 Google API 获取的数据。

2. 访问的数据（Data We Access）

经所有者本人通过 Google OAuth 2.0 明确授权后，本应用访问且仅访问所有者本人的 Gmail 账号中的以下数据：

  • 邮件内容与元数据：邮件正文、主题、发件人/收件人、时间戳、标签（用于搜索、读取、整理、归档、起草与发送邮件）；
  • 邮件设置：标签与过滤器的创建、读取和修改；
  • 附件：应所有者要求下载指定邮件的附件。

本应用不收集本页面访问者的任何信息，不收集任何第三方用户的个人信息。

3. 数据的使用（How Data Is Used）

上述数据仅用于以下目的，不作任何其他用途：

  • 按所有者指令对其本人邮箱执行搜索、整理、打标签、建过滤器、归档；
  • 代表所有者起草与发送邮件（均经所有者明确指示）；
  • 维护邮箱组织状态（标签、过滤器）。

4. 数据的存储与安全（Storage & Security）

  • Google OAuth 访问令牌仅存储在所有者本人的设备上，不上传至任何第三方服务；
  • 工作文件与配置仅在所有者本人的设备与其个人私有云存储（阿里云 OSS 私有桶，仅所有者可访问）之间同步；
  • 本应用不建立任何中央用户数据库。

5. 数据的共享（Sharing）

本应用不会将任何数据出售、出租、交易或分享给任何第三方；不将数据用于广告、数据分析或任何第三方利益目的。

6. 数据的保留与删除（Retention & Deletion）

本应用不主动持久化存储邮件内容；所有操作均实时通过 Gmail API 完成，结果直接反映在所有者本人的 Gmail 账号中。所有者可随时：

  • 通过 Google 账号权限页撤销本应用的授权，立即终止全部数据访问；
  • 删除设备上的凭证文件以清除本地令牌。

7. Google API 合规（Google API Compliance）

本应用遵守 Google API 服务条款与 Google API 服务用户数据政策，包括其中的 Limited Use（有限使用）要求；不将 Google API 用于 AI NCII（AI 生成的未经同意的亲密影像）或任何被禁止的用途。

8. 政策更新

本政策如有更新，以本页面所示日期生效。

9. 联系方式

如有疑问，请通过 Google Cloud Console 中本应用登记的支持邮箱与所有者联系。

English summary: Awawaya is a personal-use application that accesses only its owner's own Gmail account after the owner's explicit Google OAuth consent, using scopes gmail.modify and gmail.settings.basic. Data accessed (email content and metadata, labels, filters, attachments on request) is used solely to search, organize, label, filter, archive, draft and send the owner's email per the owner's instructions. OAuth tokens are stored only on the owner's devices; files sync only between the owner's devices and the owner's private cloud storage. No data is sold, rented, shared with third parties, or used for advertising. No central user database exists; no third-party personal data is collected. The owner may revoke access at any time via Google Account permissions. The app complies with the Google API Services Terms of Service and User Data Policy, including Limited Use, and does not use Google APIs for AI NCII or any prohibited purpose.
