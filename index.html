Awawaya

个人生产力工具 · Personal Productivity Toolkit

关于本应用（About）

Awawaya 是一款归应用所有者个人使用的自动化与效率工具集，基于 ZCode Agent 运行环境构建。本应用不面向公众提供服务，不进行商业化运营。

应用用途（Purpose）

  • 邮件管理 —— 经应用所有者本人通过 Google OAuth 明确授权后，使用 Gmail API 对其本人邮箱执行：搜索与读取邮件、管理标签与过滤器、整理归档、起草和发送邮件。
  • 个人配置同步 —— 在应用所有者本人的设备之间同步工具配置与工作文件（不涉及任何 Google 用户数据）。

权限与数据使用（Permissions & Data Use）

本应用仅申请以下 Google OAuth 权限范围，且仅在所有者本人授权后访问其本人数据：
• gmail.modify（读取 / 整理 / 发送邮件）　• gmail.settings.basic（标签、过滤器设置）

访问凭证（OAuth 令牌）仅保存在所有者本人的设备上。本应用不收集任何第三方用户数据。

合规声明（Compliance）

  • 本应用遵守 Google API 服务条款及 Google API 服务用户数据政策（含 Limited Use 有限使用要求）。
  • 本应用不将 Google API 用于生成 AI NCII（AI 生成的未经同意的亲密影像）或任何其他未授权、被禁止的用途。
  • 本应用不会将用户数据出售、出租或用于广告或第三方利益目的。
English summary: Awawaya is a personal-use productivity toolkit owned and operated solely by its developer. With the owner's explicit Google OAuth consent, it uses the Gmail API (scopes: gmail.modify, gmail.settings.basic) to search, read, label, filter, archive, draft and send email in the owner's own mailbox, and to sync tool configuration among the owner's own devices. It collects no third-party user data, stores OAuth tokens only on the owner's devices, and complies with the Google API Services Terms of Service and User Data Policy including the Limited Use requirements. It does not use Google APIs for AI NCII or any prohibited purpose.
